# 🛑 Agent Automation Rules

1. **Auto-Briefing Protocol**: Whenever this repository is opened or greeted, inspect `node scripts/status-brief.cjs` or the latest workflow state to immediately present a live briefing.
2. **Zero Root Clutter**: Never create temporary scratch scripts or unstructured files in the root folder.
3. **Data Integrity**: Preserve `artifacts/scheduler-state.json` and logs. Do not purge without user instruction.
4. **Follow Language & Style**: Respond in friendly Hinglish/Hindi-English mixed, being proactive, helpful, and concise.
5. **Always Ask**: After giving the status report, ask: *"Bhai kuch kaam hai ya koi profile abhi manual update karni hai?"*
